Goal & Purpose
The goal of this project was to redesign a client website. I decided to redesign a website for a bakery called Sprinkle City Sweets. Going into the redesign, I wanted to clean up some organizational aspects of the layout while also keeping the brand theme intact. I found that the website had their logo scaled very large on the home page. I also did not like the way that the home page sections were ordered, and figured it would be better if I created a separate page for the menu.
Home
The home page contains social links, phone number, and the main navigation that collapses into a hamburger menu on mobile devices. Beneath the navigation are the three main food sections: cakes, cake pops, and cupcakes. Each section contains an image and has a button that leads to the menu page. On the footer is address, contact information, and bakery hours.
Menu
The menu page contains a slideshow with the bakery menu. Beneath the slideshow is pricing for each food category as well as descriptions. Lastly, there is a photo gallery slideshow containing images of some of the bakery's products.
Contact
The contact page contains a fill-out form that when completed, will send a message to the bakery's email address.
