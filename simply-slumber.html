Goal & Purpose
The goal of this project was to design an app interface for the iPhone. I decided to design an interface for an app I created called SimplySlumber. It is a sleep tracking app that focuses on sleeping aid. SimplySlumber is ideal for those who have sleeping disorders or conditions, and those who want to improve their sleeping habits and get more sleep.
App Icon
The app icon consists of a night sky filled with stars along with the illuminated double S’s that stands for SimplySlumber. The icon depicts the nighttime with cool colors, reflecting the atmosphere of the app design and experience.
Sign-In
Upon opening SimplySlumber, there is a opening screen followed by a sign-in screen. The user can use the app as a guest, sign-in if they already created an account, or create an account for the first time.
Home
Sleeping stats can be viewed on the home page. Stats are based on the amount of time the user spends in each sleep phase and at which time they reached each phase. There are also sleeping tips.
Calendar
The calendar will show all the days that a user has tracked their sleep. The user can select a custom date range from here and view their average stats for that specific frame of time on the home page.
Profile
The user can edit and customize their own profile here. In addition, they can set their sleeping recommendation based on their age and gender, or they can set their own personal goal.
Trackers
The user can create and edit their own trackers here. Trackers come with an alarm option if the user wants an alarm to wake them up. Once the tracker is stopped, the user will have access to their stats.
Meditation/Bedtime Stories
Having trouble sleeping? These pages contain free and paid libraries of meditation guides and bedtime stories to assist the user fall asleep more easily.
Audio Library/Player
The audio library provides a list of sample sounds that the user can listen to as they go to bed. The user can also choose to import their own audio if they want. The audio player includes a sleep timer, which will automatically stop music after a specific amount of time, and also customizable equalizer settings, which changes levels of frequencies in the audio.
